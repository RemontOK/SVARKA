# Анализ проекта "АльфаСмарт" - Интернет-магазин сварочного оборудования

## Общая информация

**Название проекта:** svarka (АльфаСмарт)  
**Тип проекта:** React SPA (Single Page Application) - интернет-магазин сварочного оборудования  
**Версия React:** 19.2.0  
**Роутинг:** React Router DOM 7.9.6  
**Сборщик:** Vite 7.2.2  
**Деплой:** GitHub Pages

## Структура проекта

```
svarka/
```

## Технологический стек

### Основные технологии:
- **React 19.2.0** - UI библиотека
- **React Router DOM 7.9.6** - маршрутизация
- **Vite 7.2.2** - сборщик и dev-сервер
- **CSS** - стилизация (без препроцессоров)

### Особенности:
- Использование CSS переменных для тем
- Context API для управления темой
- LocalStorage для сохранения выбранной темы
- Адаптивный дизайн (mobile-first)
- SEO-оптимизация (структурированные данные)

## Цветовая схема

### Светлая тема:
- Фон: `#ffffff`, `#faf8f3`, `#f5f3ed`
- Текст: `#1a1a1a` с различной прозрачностью
- Бренд: желтый `#f8c400`, красный `#ff3b3b`
- Границы: `rgba(0, 0, 0, 0.08)`

### Темная тема:
- Фон: `#050505`, `#1a1a1a`, `#252530`, `#2d2d3a`
- Текст: `#f4f4f4` с различной прозрачностью
- Бренд: те же цвета (желтый, красный)
- Границы: `rgba(255, 255, 255, 0.08)`
